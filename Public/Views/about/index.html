О сайте

Вэб-сервер сайта был разработан с помощью языка Си создателсями самого сайта. Это было сделано для того, чтобы разработчики имели полный контроль над сайтом и могли предоставить максимальное качество.

Сайт же был написан на HTML + CSS + JavaScript без использования дополнительных фреймворков всё с той же целью — как можно меньше нагружать сайт, чтобы он работал быстрее.

О хостинге

Хостингом сайта является Oracle Cloud, защиту и сертефикат ssl сайту предоставляет Cloudflare.
