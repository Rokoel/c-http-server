О сайте

Веб-сервер сайта был разработан на языке C его создателями. Это было сделано для того, чтобы разработчики имели полный контроль над сайтом и могли обеспечить максимальное качество.

Сайт же был написан на HTML + CSS + JavaScript без использования дополнительных фреймворков всё с той же целью — как можно меньше нагружать сайт, чтобы он работал быстрее.

О хостинге

Сайт размещён в Oracle Cloud, а защиту и SSL-сертификат предоставляет Cloudflare.
